You can delete a branch directly on the GitHub website or by using Git commands in your terminal.

Method 1. On the GitHub Website

This method removes the branch from your remote repository on GitHub.
• Open the branches page. Go to your repository's main page, click the branch dropdown menu at the top left, and select View all branches.
• Delete the branch. Find the branch you want to remove and click the trash can icon next to it.
• Restore if needed. If you click the trash icon by mistake, a temporary Restore button will appear on the same line until you refresh the page.
Note: You cannot delete a repository's default branch directly. You must first assign a different branch as the default in your repository settings before deleting the old one.

Method 2. Using the Command Line (Git)

Deleting a branch on GitHub does not remove it from your local computer, and deleting it locally does not remove it from GitHub. Use both commands below for a complete cleanup.
